# Rear-Mounted CNC Version

This folder contains STEP models for the rear-mounted CNC version. The original STEP files are provided directly for download.

- `Rear Upper Right M3.step` — rear upper right M3 part
- `Rear Upper Left M3.step` — rear upper left M3 part
- `Rear Lower Left M3 (Variant 1).step` — rear lower left M3 part, variant 1
- `Rear Lower Left M3 (Variant 2).step` — rear lower left M3 part, variant 2
- `Rear CNC Carbon Fiber and Aluminum Universal.step` — universal rear CNC part for carbon-fiber and aluminum setups

The two lower-left source files had similar Chinese names but different contents, so both are retained as separate variants.
